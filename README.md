# Book-Management-System-DB

This repository contains the database schema design for a Book Management System (BMS). The database consists of tables for books, authors, and categories, and it is normalized to the third normal form (3NF).

## Steps Involved:

1. Create tables for Book, Author, and Category.
2. Define relationships between the tables (e.g., one-to-many between Author and Book).
3. Designed the schema in 3NF.
4. Use VSCode SQL Tools to execute SQL queries.

## Setup Instructions:

1. Clone this repository.
2. Open the SQL files in your preferred SQL editor (VSCode or MySQL Workbench).
3. Execute the scripts to create the tables and relationships.
